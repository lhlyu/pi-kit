# 状态栏

仅在交互式终端显示，无需配置。

```text
⚡️ TPS: 50.0 tok/s 🚀 TTFT: 1.23s ⌛️ TS: 2m35s
```

## 指标

- **TPS**：输出速度，优先使用服务端用量，否则实时估算；调用结束后显示平均速度。
- **TTFT**：当前模型调用开始到首次输出的耗时，包含文本、思考或工具参数。
- **TS**：本轮总耗时，包含自动重试、工具等待和后台子任务。

TPS、TTFT 暂无数据时显示 `--`，后续调用等待时保留上次结果。

## 后台子任务

配合 `pi-subagents` 使用时，后台子任务运行期间 TS 持续累计；父任务继续处理结果时计时不中断。全部结束后可能稍等数秒才定格，不计入额外等待时间。

`/reload` 前已运行的后台任务不会恢复计时，新启动的任务不受影响。
